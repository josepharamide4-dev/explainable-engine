# Explainable CLI

Explainable CLI is a Python developer tool for debugging, regression detection, performance analysis, and team-context workflows.

## Install

```bash
pip install explainable-engine
```

## Usage

```bash
explainable --help
```

## Example commands

```bash
explainable scan .
explainable perf core/scanner.py
explainable perf-summary .
explainable doctor
explainable check .
```

## Features

- Python debugging workflows
- Regression detection and baselines
- Performance analysis and comparisons
- Team-context and workflow commands
- Installable CLI via PyPI
